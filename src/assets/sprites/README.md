# Sprites de personaje (arte final)

Hojas de 4 direcciones (sur·norte·este·oeste, en ese orden, una al lado de la
otra) listas para el loader del juego — reemplazan a `makeCharacter()`
(`src/util/textures.ts`), que hoy dibuja los muñequitos placeholder por código.

No se sueltan archivos acá a mano: se arman a partir de lo que cae en
`src/assets/sprites-raw/` (ver el README de esa carpeta y
`docs/06-prompts-sprites.txt` para los prompts de generación).
